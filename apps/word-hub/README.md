# 词枢 · 英语记词器 WordHub v1.24

基于 SM-2 间隔重复算法的本地背单词应用，内置 ECDICT 开源词典（77 万词条数据库筛取）。

## 词库（6 个，可自选）
- CET-4 四级（3849 词）
- CET-6 六级·含四级（5805 词）
- 考研词汇（4801 词）
- 雅思 IELTS（5040 词）
- 托福 TOEFL（6974 词）
- GRE 词汇（7504 词）

词条按语料词频排序——先学最常见的。每张卡片含：音标、中文释义、英文释义、词形变化（过去式/复数等）。

## 两种学习模式（首页鼠标点击切换）
- **卡片模式**：看单词忆释义，点卡翻面
- **拼写模式**：看中文释义 + 首字母提示，键入英文单词（回车提交）自动判对错。
  **看答案/提交后，正确拼写会直接填进上方那行空缺**：答对变绿、答错变红，**「看答案」只把字母补上，
  字体/字号/颜色与点击前完全一致**（不算答错，不再标红），并配逐字淡入动画。
  翻面后释义、例句、词形依次柔和浮现。另配 🔊 发音辅助；提交后仍需自评（忘记/模糊/认识），评分逻辑与卡片模式一致

## 记词顺序（首页快捷选择，v1.5 新增）
- **⬇ 正序（按词频）**：从最高频的词开始，复习队列按到期日先后 —— 默认
- **🔀 乱序（随机抽）**：从全部未学词中随机抽取每日词数，复习队列也打散 —— 适合考前混眼熟
- 选择会记住，并随进度导出/导入一起迁移

## 鼠标操作（v1.5）
翻面后点下方 **😵 忘记 / 🤔 模糊 / 😃 认识** 按钮即可切到下一张，**全程可只用鼠标**；
键盘快捷键 `1` `2` `3`（评分）与 `空格`（翻面）依然可用。

## 每日词数（首页快捷选择）
首页一键切换 10 / 20 / 30 / 50 / 80 词，或到「设置」输入任意数量（1-100）。

## 收藏夹
复习时点卡片右上角的 **★** 收藏生词；「收藏夹」页可查看全部收藏、移除、或一键 **▶ 复习收藏的词**（考前突击模式）。收藏按词库分别保存。

## 使用
双击 `index.html`。学习进度自动保存在浏览器 localStorage，刷新/关闭不丢失。

- **今日任务**：选词库 → 选每日词数、学习模式与记词顺序 → 开始学习
- **「正在学」和「复习」是两个独立板块**（v1.12 起）：
  - 导航里并列两条：**「正在学」**= 今日新词（点首页「开始学习」就落在这里）、
    **「复习」**= 到期复习（只放学过且到期的词）。学新词不再跳到标着「复习」的页
  - 首页也拆成两块：左边「正在学 · 今日 N 新词」，右边「复习 · M 个到期」，各自一个按钮
  - 完成页按板块区分：新词那块说「今日新词学完了！」并给「再学一点」；复习那块说「这一轮复习完成！」，
    且只报"复习 N 次"，不会把两个板块的计数混在一起
- **「复习」页签只复习学过的词**（v1.9 起与新学彻底分开）：点「复习」进的是**到期复习会话**，
  只放已学过且到期的词（按到期日先后）；没有到期词就明确显示「暂时没有要复习的词 · 学过的词到期后会自动出现在这里」。
  页签上有个小蓝点显示当前到期词数。首页「开始学习」走的才是**今日新词会话**，两者互不干扰
- **「再学一点」**：走完今日任务后，按钮自动变成「再学一点 →」（只要词库还有没学过的词），
  点一下再发一批新词、**接着往下学**（不是从头开始）；完成页 🎉 也有同样入口。
  词库真学完了才变回禁用的「今日已完成 🎉」
- **复习**：卡片模式空格/点击翻面；拼写模式输入后回车；点下方按钮或按 `1` 忘记（队尾重刷+明天再现）· `2` 模糊 · `3` 认识
- **翻面动画不会闪出滚动条**（v1.15）：卡片翻转用的是 3D 透视，而**透视越强、卡片转到侧面时
  投影包围盒膨胀得越厉害**，会越过视口底边把页面顶出滚动条（实测写死 2800px 时，1345 宽的窗口没事，
  2100 宽的窗口会溢出 35px，滚动条出现一两秒才消失）。所以透视距离**按卡片尺寸实时计算**
  （`fitFlipPerspective()`，卡片越大取值越大），任何窗口尺寸都不会越界
- **卡片正反面都能发音**：翻面后右上角（单词右边、★ 左边）也有 🔒 按钮 —— 释义都看到了还想再听一遍，不用翻回去
- **卡片高度跟着面板自适应**（v1.14）：不再用「视口高度减去某个常数」硬算 —— 队列预览会按窗口宽度折行、
  评分区是翻面后才出现的，常数估小就会翻一次出一回滚动条。现在交给 flex 分配，上下占多少卡片就自动少多少；
  评分区/下次间隔用 `visibility` 常驻占位，**翻面时卡片也不会跳一下**
- **发音**（v1.13 起改为真人读音）：点卡片上的 🔊，或开「翻面自动发音」。
  三级兜底：**① 在线真人读音**（词典发音，美音/英音分开）→ **② 系统自带英文语音** → ③ 浏览器语音合成。
  在线音频会**按词缓存到本地**（`%LOCALAPPDATA%\WordHub\audio`，一条约 15 KB，最多 4000 条自动清旧），
  翻到新卡时后台预取，所以点 🔊 基本是即时的；断网或该词查不到时自动退回系统语音，不会没声音。
  > 之所以要这层兜底：新版 Edge/WebView2 改成枚举 OneCore 语音后，系统没装英文语音包时
  > `speechSynthesis` 里一个英文语音都没有，浏览器会拿中文语音念英文单词
- **统计**：连续打卡、**复习热力图（近 52 周，带月份/星期标签）**、词库进度条（上行下条、三列铺开）；统计页整页用卡片分组，两档字号都不出现滚动条
- **设置**：美音/英音、**字体大小 / 主题（浅色·深色）**、进度导出/导入 JSON（换电脑迁移用）

## 朗读小窗（v1.17 新增）

一个**独立的小窗口**，定时朗读单词并自动切换 —— 当"单词电台"用：挂在一角，边干别的边磨耳朵。

- **入口**：窗口栏右侧的 🔊 按钮，或「设置 → 学习」标题右侧的「🔊 朗读小窗」胶囊
- **小窗内容**：单词 + 音标 + 中文释义，下面是播放控制与进度
- **定时朗读**：默认每 **3 秒**一个词（可切 2 / 3 / 5 / 8 秒），读完自动切下一个，到末尾回到开头
- **顺序 / 随机**可切换：随机是**洗牌**（整轮打乱、一轮内不重复，当前词放最前不打断；一轮播完重新洗牌），⏮ ⏭ 也按洗牌后的顺序走
- **内容随窗口等比缩放**：拉大小窗，单词/列表/控件整体跟着变大变小
  （按窗口宽度设置小窗容器的 zoom；拉伸放大后**不会出现滚动条**，内容正好铺满窗口）
- **手动**：⏮ 上一个 / ⏯ 播放暂停 / ⏭ 下一个；键盘 <kbd>空格</kbd> 播放暂停、<kbd>←</kbd> <kbd>→</kbd> 切换
- **📌 置顶**：默认置顶，方便压在别的窗口上看；可以关掉
- **词从哪来**（可切）：**整本词库**（默认，如 CET4 全 3849 词，按词频序）/ **正在学的队列**（今日新词 + 到期复习，与主窗实时同步）
- **口音**：小窗里可切 **美音 / 英音**，且是**独立设置** —— 改小窗不会影响主窗口的发音口音
- **重复次数**：每个词可念 **×1 / ×2 / ×3** 遍再切下一个（默认 ×1）
- **播放列表**（📋）：点标题栏的 📋 切到列表视图
  - 默认只渲染当前词**前后各 20 个**（几千词的列表不会一次性全建出来），
    往下滚或往上滑会**增量加载**更远的词（滑到顶时会自动补偿滚动位置，不跳）
  - 当前词**高亮**；点任意一个词就跳过去（播放位置与词卡同步）
  - 顶部**搜索框**：输入单词回车，跳到该词并重新以它为中心展开
- **朗读**走和主界面同一套发音链路（在线真人读音 + 本地缓存 + 系统语音兜底），不需要额外配置

- **小窗可拉升放大**：拖小窗的**右边缘 / 下边缘 / 右下角 / 左下角**（顶部留给标题栏拖动）
- **小窗的词库与主窗互不相通**：小窗顶栏有「词库」下拉（6 个词库任选），选完记在本机；
  小窗换词库不会动主窗设置，主窗换词库也不影响小窗
- **修「点主窗口最顶层会刷新、拖不动」**：之前缩放热区的层级压住了标题栏，点最顶端触发的是缩放
  而不是拖动。现在标题栏层级提到热区之上，且**上边 4px 保留为缩放**（其余标题栏区域用于拖动）
- **小窗标题栏的关闭键与主窗同款**：12px 红色圆点，悬停显 ✕（命中区 24×24）
- **打开小窗默认不自动开始朗读**：要播自己按 ▶（避免一打开就出声）
- **词库与小窗互通关系**：小窗用**自己那份词库**，与主窗口**互不相通** —— 小窗换词库不会动主窗设置，主窗换词库也不影响小窗。顶栏的「词库」下拉里 6 个词库任选，选完记在本机
- **关掉小窗会停止朗读**：计时器停掉，同时把手上正在念的那句掐掉（在线音频与系统语音都停）

## 例句（v1.6 新增）
翻面后的卡片背面会显示一条**例句 + 中文翻译**，句子里的目标词连同它的词形变化（复数、过去式、-ing 等）
用**重点色高亮**标出，中文用文楷排印。

- 语料来自 OPUS 公开中英平行语料 TED2013，按「完整整句 + 中文含汉字 + 目标词整词命中 + 句子尽量短」自动筛选
- 覆盖率：CET-4 95% / 考研 94% / CET-6 92% / 雅思 89% / 托福 77% / GRE 56%（全库 9748 词有例句）
- 库里没有的词标注「（该词暂无例句）」，不影响学习；缺 `data_sent.js` 时该区块自动降级，学习功能不受影响

## 算法
**复习节奏**（设置 → 学习，默认「每天复习」）：

| 模式 | 行为 |
|---|---|
| **每天复习（默认）** | 学完 / 复习完 → **第二天过 0 点即可再复习**（认识、模糊都一样）；「忘记」的词当天入队尾重刷 |
| 渐进间隔（SM-2） | 认识 → 间隔 1 → 6 → 15 → 38 → 95 …天（I3 = I2 × EF；EF 区间 [1.3, 2.5]，随「模糊」降、随「认识」升）；模糊 → 间隔×0.75 且 EF−0.15；忘记 → 重置回 1 天 |

间隔按**天**算（本地零点为界），所以早上学完，第二天一打开就会出现在「复习」页签里。数据来源 skywind3000/ECDICT（开源词库）。

## 发给别人用（分发说明，v1.16）

单文件 exe（约 34 MB），**不用安装、不用管理员权限、断网也能用**，直接发过去双击就行。
有三件事提前跟对方说一声，能省掉一轮"打不开 / 好丑 / 是不是病毒"：

1. **需要 Edge WebView2 运行时** —— Windows 11 自带；Windows 10 一般也随 Edge 装过。
   万一没有，程序启动时会**弹窗提示并给出官方下载地址**（约 2 MB），装完再打开即可。
   （缺它时程序只能用系统自带的旧版内核渲染，会明显变慢、排版错乱 —— 所以别忽略那个提示。）
2. **SmartScreen 会拦一下** —— exe 没有代码签名，从微信 / 网盘 / 邮箱下载后首次运行会提示
   「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**。
3. **杀毒软件可能误报** —— PyInstaller 打出来的单文件 exe 比较容易被 360 / 火绒 之类拦，
   加进白名单即可（源码就在本仓库，可自行复核）。

**学习记录存在哪**：`%LOCALAPPDATA%\WordHub\webview`（WebView2 的用户数据目录）。
⚠️ 绝不能放临时目录 —— pywebview 默认是"无痕模式"，会把用户数据放进 `%TEMP%` 并在关窗时删掉，
那样**一关程序进度就全没了**（v1.16 修的就是这个）。
换机器 / 换浏览器时用程序里的「导出 / 导入 JSON」。

## 桌面版（exe，v1.7 新增）
`词枢记词器.exe`（约 23 MB，单文件，双击即用，**不需要装 Python 或浏览器**）：

- 用系统自带的 **WebView2**（Win10/11 内置）当渲染内核：先起一个只监听 `127.0.0.1` 的本地服务，再开原生窗口 ——
  体积比 Electron 小一个数量级（23 MB vs 200 MB+）
- 桌面快捷方式：`词枢记词器.lnk` → exe；原网页版入口保留为 `词枢记词器（网页版）.lnk`
- 学习进度存在 WebView2 的用户数据目录，与网页版**互相独立**；换版本时用设置里的导出/导入 JSON 搬迁
- **固定默认尺寸**（窗口 1360×900）：页面实际拿到 1345×874 CSS 像素，实测六个页签 × 两档字号全部零溢出，**不会出现上下滚动条**；
  窗口仍可自由缩放，最小 1075×875 —— 小于这个高度统计/设置页会开始滚动，所以做了下限保护
- 统计页的热力图与词库进度是**左右两列**排布（竖排会顶出滚动条）
- **窗口拖动 / 缩放 / 三颗按钮都走「页面驱动」的节流链路**（v1.11 重做）：
  - 拖动不再用 pywebview 内置的 drag region（它每次 `mousemove` 都过一次 JS→Python 桥调 `SetWindowPos`，不节流），
    改成页面自己实现：**指针捕获**（松手一定收得到）+ **rAF 合帧**（一帧最多发一次，只发最新位置），
    `pointercancel` / 丢失捕获 / 窗口失焦都会兜底收尾 —— 不会出现「窗口一直跟着鼠标跑、按钮点不动」
  - 拖动 / 缩放期间给 `body` 加 `win-interacting`，临时**关掉 header 与窗口栏的 `backdrop-filter`**
    （全宽高斯模糊每次移动窗口都要重算，是拖动发涩的主因）；缩放的位置+尺寸合并成**一次 SetWindowPos**
  - 三颗按钮圆点仍是 12px，但**命中区用伪元素扩到 24×24**（12px 太难点准）
- **窗口栏是 macOS 风格**：去掉了系统标题栏，**三颗圆点在右上角**（黄=最小化 / 绿=缩放 / 红=关闭，按 Windows 习惯排），标题在左侧，
  悬停显字），中间显示标题，**拖这条栏可移动窗口、双击=缩放**；窗口仍可从八条边缘/角拖拽缩放
